ACCOUNT INTEGRATION

Connect your Instagram.

Use Meta’s official tools to bring eligible account insights into InstaPulse.

▣ Official API path
◎

Bring your real metrics in.

InstaPulse currently runs in demo mode. The included backend is a starting point for Meta OAuth and Graph API integration; you’ll need to create and configure your own Meta app before real account data can load.

Before you begin

✓
Professional Instagram account

Business or Creator account; personal accounts may not expose professional insights.

✓
Meta developer app

Create an app and configure the supported Instagram API product and redirect URI.

✓
HTTPS backend + permissions

Configure the exact scopes required by your chosen API flow and complete review/access requirements where applicable.

Developer setup checklist

  1. Copy backend/.env.example to backend/.env.
  2. Set your Meta App ID, App Secret, and exact HTTPS callback URL.
  3. Deploy the backend to a public HTTPS host and add the callback URL in your Meta app.
  4. Implement and verify the OAuth callback and token exchange before enabling account access.
  5. Request only the permissions required for your use case and test with eligible accounts.
  6. Never commit secrets or long-lived access tokens to GitHub.
⌁

Privacy-first by design

Your account credentials should be handled by Meta’s authorization flow. InstaPulse should never ask for your Instagram password.

⌘

Official documentation

Review the current API setup, eligibility, permissions, and rate limits directly with Meta before launch.
